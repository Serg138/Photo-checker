ПРОВЕРКА ФОТОГРАФИЙ

ЗАПУСК
1. Положите фотографии в папку Photos рядом с PhotoChecker.exe.
2. Запустите PhotoChecker.exe двойным щелчком.
3. Нажмите «Проверить».

Программу можно запускать из любого места, в том числе ярлыком на рабочем столе.
Папка Photos определяется относительно EXE, а не относительно текущей папки запуска.
Кнопкой «Выбрать…» можно указать другую папку. Последняя папка запоминается.
Проверка запускается только вручную; наблюдения за папкой и фоновых заданий нет.
Python и интернет не нужны. Используется установленный в Windows .NET Framework 4.8.

КАК ОПРЕДЕЛЯЮТСЯ НОВЫЕ ФОТО
Первый запуск обрабатывает все фотографии в выбранной папке.
После этого программа сохраняет базу отпечатков.
Следующие запуски проверяют все новые или изменённые файлы, а не только последний по дате.
Новый файл с сохранённой старой датой тоже будет проверен.
Для ускорения неизменность существующего файла определяется по имени, размеру,
времени изменения и создания. При намеренной подмене файла с сохранением всех
этих признаков следует сбросить базу папки.
Список результатов включает все найденные совпадения, включая прежние.
Чтобы принудительно проверить всё заново, закройте программу и переименуйте
папку PhotoCheckerData рядом с EXE — при следующем запуске будет создана новая база.

РЕЖИМ ПО УМОЛЧАНИЮ: ТОЧНОЕ СОВПАДЕНИЕ ПИКСЕЛЕЙ
Фото читаются в полном разрешении, с учётом поворота EXIF, и приводятся к RGB24.
Для прозрачных изображений используется белый фон.
Сравнивается SHA-256 размеров и всех пикселей; имена, JPEG-комментарии и другие
служебные метаданные не входят в отпечаток. Байты файлов могут различаться.
Миниатюры в этом режиме вообще не создаются.
Другой размер или повторное JPEG-сжатие обычно меняют пиксели: такие версии
точный режим не объединяет. Для них включите поиск похожих.
У файлов GIF и многостраничных TIFF проверяется только первый кадр/страница.

ПОИСК ПОХОЖИХ (ВКЛЮЧАЕТСЯ ГАЛОЧКОЙ)
Сначала находятся точные совпадения, затем кандидаты по pHash и dHash.
BK-дерево уменьшает количество сравнений отпечатков.
Кандидаты проверяются по SSIM структуры и среднему цветовому отличию.
Рабочие уменьшенные изображения создаются только в памяти и никогда не сохраняются.
Порог pHash: 10 бит; dHash: 14 бит; отношение сторон: отклонение до 1%;
SSIM: от 0,94; среднее абсолютное цветовое отличие: не более 0,055 (шкала 0–1).
Похожие кадры отмечаются «Похожи — проверить»: это кандидаты, а не доказательство
того, что исходный снимок один и тот же. Обрезки и надписи специально не ищутся.
Параметры проверены на искусственных примерах; на ваших фото они не калибровались.

РЕЗУЛЬТАТ
Каждая строка показывает файл и имя совпадающего/похожего файла.
Полный путь виден при наведении на имя; обе кнопки под таблицей показывают
соответствующий файл в Проводнике.
В группе точных копий каждый файл сравнивается с одним представителем группы,
поэтому группа из 5 одинаковых фото выводится четырьмя строками.
Число «совпадений» — количество строк, а не число всех возможных пар.
Никакие фотографии не удаляются, не перемещаются и не переписываются.

СЛУЖЕБНЫЕ ДАННЫЕ
PhotoCheckerData рядом с EXE содержит настройки и отдельную базу для каждой папки.
Внутри базы: cache.json, «Последняя проверка.txt» и «Совпадения.csv».
Отчёты перезаписываются после успешного завершения очередной проверки.
В CSV используется разделитель «;» и UTF-8 BOM.
Для работы программа должна иметь право записи рядом с EXE.

ФОРМАТЫ И ОБЛАСТЬ ПРОВЕРКИ
JPEG/JPG/JFIF, PNG, BMP, GIF, TIFF. Только файлы непосредственно в выбранной папке.
Подпапки не обходятся. HEIC/HEIF, WEBP и AVIF отмечаются как неподдерживаемые.
Повреждённые или занятые файлы выводятся в отчёте как ошибки, проверка остальных
продолжается. При ошибках программа явно сообщает, что проверка неполная.
