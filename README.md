# Photo Checker

Программа для Windows, которая находит одинаковые и похожие фотографии в одной папке. Предназначена, в частности, для снимков из WhatsApp с разными именами файлов.

Работает локально и запускается вручную. Фотографии не отправляются в интернет, не удаляются и не перемещаются.

## Быстрый запуск

1. Скачайте репозиторий архивом и распакуйте либо клонируйте его.
2. Положите фотографии в папку `Photos` рядом с `PhotoChecker.exe`.
3. Запустите `PhotoChecker.exe` и нажмите **«Проверить»**.
4. Посмотрите найденные пары файлов. Кнопки под таблицей показывают выбранный файл и его совпадение в Проводнике.

EXE можно запускать через ярлык из любого места: папка `Photos` определяется относительно расположения программы. Кнопка **«Выбрать…»** позволяет указать другую папку; программа запоминает последний выбор. Проверяются только файлы непосредственно в выбранной папке, без подпапок.

Требуется Windows с **.NET Framework 4.8**. Python, дополнительные библиотеки и интернет для работы программы не нужны. Рядом с EXE должно быть разрешено создание служебных файлов.

## Как выбираются фотографии для проверки

При первом запуске программа обрабатывает все фотографии и сохраняет их отпечатки. При следующих запусках она обрабатывает все новые или изменённые файлы и использует базу для остальных.

Выбор не зависит от того, какой файл последний по дате: добавленный снимок со старой датой тоже проверяется. Неизменность существующего файла определяется по имени, размеру, времени изменения и создания. Если намеренно заменить файл, сохранив все эти признаки, для повторной обработки потребуется сбросить базу.

Результаты включают все найденные совпадения, в том числе обнаруженные ранее.

## Режимы сравнения

### Точное совпадение — включено по умолчанию

Изображения читаются в полном разрешении с учётом поворота EXIF и приводятся к RGB24. Сравнивается SHA-256 размеров и всех пикселей изображения. Имена файлов, JPEG-комментарии и прочие служебные метаданные не входят в отпечаток.

Это сравнение содержимого изображения: файлы с разными байтами могут содержать одинаковые пиксели и будут найдены как совпадение. Миниатюры в этом режиме не создаются.

Повторное JPEG-сжатие или изменение разрешения обычно меняет пиксели. Для таких копий используйте поиск похожих. Прозрачность сводится к белому фону; у GIF и многостраничного TIFF проверяется только первый кадр или страница.

### Поиск похожих — включается галочкой

После точных совпадений программа ищет кандидатов по перцептивным хешам pHash и dHash. Для поиска близких отпечатков используется BK-дерево. Затем кандидаты сравниваются по структуре изображения (SSIM) и цветовому отличию.

Рабочие уменьшенные изображения создаются только в памяти. Файлы миниатюр на диск не записываются. Результаты подробного сравнения пар сохраняются в базе и используются повторно.

Похожие изображения отмечаются **«Похожи — проверить»**: очень близкие отдельные кадры могут оказаться кандидатами, а перцептивная проверка не гарантирует нахождение всех копий. Обрезанные изображения и версии с надписями специально не обрабатываются.

Текущие пороги:

| Проверка | Порог |
| --- | --- |
| Расстояние pHash | Не более 10 бит |
| Расстояние dHash | Не более 14 бит |
| Отклонение отношения сторон | Не более 1% |
| SSIM | Не менее 0,94 |
| Среднее абсолютное цветовое отличие | Не более 0,055 по шкале 0–1 |

Пороги проверены на искусственных примерах и не калибровались на пользовательской коллекции.

## Результаты и служебные данные

В таблице показаны имена обоих файлов и их статус: новый, изменённый или взятый из базы. Полный путь виден при наведении на имя.

Для группы точных копий каждый файл сопоставляется с одним представителем: пять одинаковых фото дадут четыре строки. Счётчик совпадений показывает количество строк. Для похожих изображений выводятся проверенные пары, без объединения по цепочке сходства.

Папка `PhotoCheckerData` рядом с EXE содержит настройки и отдельную базу для каждой проверяемой папки:

- `cache.json` — отпечатки изображений и результаты сравнения пар;
- `Последняя проверка.txt` — отчёт с полными путями и ошибками;
- `Совпадения.csv` — таблица совпадений, UTF-8 BOM, разделитель `;`.

Отчёты обновляются после завершения проверки. Повреждённые, недоступные и неподдерживаемые изображения отмечаются в отчёте; программа сообщает, если проверка неполная. Отмена проверки сохраняет предыдущую базу.

Для полного пересчёта закройте программу и переименуйте `PhotoCheckerData`: при следующем запуске будет создана новая база.

## Поддерживаемые форматы

JPEG/JPG/JPE/JFIF, PNG, BMP, GIF, TIFF/TIF. HEIC/HEIF, WEBP и AVIF пока не поддерживаются и отмечаются в отчёте.

## Структура проекта

```text
PhotoChecker.exe                Готовая программа
Photos/
  .gitkeep                      Сохраняет папку в Git без фотографий
PhotoChecker-README.txt          Инструкция для запуска без GitHub
tools/photo-checker/
  PhotoChecker.cs               Исходный код и самопроверки
  app.manifest                  Манифест Windows и поддержка масштабирования
  build.ps1                     Сборка EXE
```

Содержимое `Photos`, фотографии в любых каталогах проекта, локальная база, отчёты и результаты тестов исключены через `.gitignore`. В репозитории сохраняется только файл `Photos/.gitkeep`; после клонирования папка готова для добавления фотографий. Готовый `PhotoChecker.exe` включён в репозиторий.

## Сборка

Исходный код написан на C# с Windows Forms. Сборка использует компилятор из установленного .NET Framework; NuGet и сторонние пакеты не нужны.

В PowerShell из корня проекта:

```powershell
.\tools\photo-checker\build.ps1
```

Результат — `PhotoChecker.exe` в корне проекта. После изменения исходников EXE нужно собрать заново.

## Проверки

Для запуска встроенных проверок в PowerShell:

```powershell
$testOutput = Join-Path $PWD 'tools\photo-checker\test-output'
$process = Start-Process -FilePath '.\PhotoChecker.exe' `
    -ArgumentList @('--self-test', ('"' + $testOutput + '"')) `
    -WindowStyle Hidden -Wait -PassThru
Get-Content (Join-Path $testOutput 'self-test.txt')
$process.ExitCode
```

Тесты создают собственные искусственные изображения внутри указанного тестового каталога и не обращаются к пользовательской папке `Photos`. Проверяются различающиеся метаданные, разные кодировки одного изображения, изменение одного пикселя, поворот, повторное использование базы, несколько новых файлов со старыми датами, изменённые и удалённые файлы, ошибки чтения, отмена, восстановление базы и поиск похожих кадров. Код возврата `0` означает успешное завершение.
